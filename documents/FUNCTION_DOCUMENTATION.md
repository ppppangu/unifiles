# find_all_text_and_image_index 函数文档

## 函数概述

`find_all_text_and_image_index` 函数用于解析 Markdown 文本，找到其中所有图片和文本片段的索引位置。

## 函数签名

```python
def find_all_text_and_image_index(text: str) -> list:
```

## 参数

- `text` (str): 输入的 Markdown 文本

## 返回值

返回一个列表，列表中的每个元素都是一个元组 `(开始索引, 结束索引, 类型)`：
- `开始索引` (int): 片段在原文本中的开始位置
- `结束索引` (int): 片段在原文本中的结束位置  
- `类型` (str): "image" 或 "text"

## 算法思路

1. **识别图片**: 使用正则表达式 `r'!\[([^\]]*)\]\(([^)]+)\)'` 找到所有 Markdown 图片语法
2. **排序图片位置**: 按开始位置对图片进行排序
3. **填充文本片段**: 遍历图片位置，在图片之间和前后填充文本片段
4. **完整性保证**: 确保所有字符都被包含在某个片段中

## 使用示例

### 示例 1: 文本和图片混合

```python
text = "开始文本![图片1](image1.png)中间文本![图片2](image2.png)结束文本"
result = find_all_text_and_image_index(text)

# 结果:
# [
#     (0, 4, "text"),           # "开始文本"
#     (4, 23, "image"),         # "![图片1](image1.png)"
#     (23, 27, "text"),         # "中间文本"
#     (27, 46, "image"),        # "![图片2](image2.png)"
#     (46, 50, "text")          # "结束文本"
# ]
```

### 示例 2: 纯文本

```python
text = "这是一段纯文本，没有任何图片。"
result = find_all_text_and_image_index(text)

# 结果:
# [(0, 15, "text")]
```

### 示例 3: 只有图片

```python
text = "![图片](image.png)"
result = find_all_text_and_image_index(text)

# 结果:
# [(0, 17, "image")]
```

### 示例 4: 连续图片

```python
text = "前文![图片1](img1.png)![图片2](img2.png)后文"
result = find_all_text_and_image_index(text)

# 结果:
# [
#     (0, 2, "text"),           # "前文"
#     (2, 20, "image"),         # "![图片1](img1.png)"
#     (20, 38, "image"),        # "![图片2](img2.png)"
#     (38, 40, "text")          # "后文"
# ]
```

## 特性

1. **完整性**: 保证原文本的每个字符都被包含在某个片段中
2. **有序性**: 返回的片段按照在原文本中的出现顺序排列
3. **准确性**: 精确识别 Markdown 图片语法，不会误识别
4. **边界处理**: 正确处理文本开头、结尾和图片之间的各种情况

## 应用场景

- **文档解析**: 将 Markdown 文档分解为文本和图片片段进行分别处理
- **内容分析**: 统计文档中文本和图片的分布
- **格式转换**: 将 Markdown 转换为其他格式时需要分别处理文本和图片
- **向量化处理**: 对文本片段进行 embedding，对图片片段进行特殊处理

## 实现细节

函数的核心算法采用"填充"策略：
1. 先找到所有图片的位置
2. 然后在图片之间和前后"填充"文本片段
3. 确保覆盖整个文本的每个字符

这种方法确保了结果的完整性和准确性。
