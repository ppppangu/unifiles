# 欢迎使用 Unifiles

Unifiles 是一个统一的文件管理系统，帮助您更高效地管理和组织文件。

## 快速开始

### 安装

```bash
# 安装依赖
npm install unifiles
```

### 基本使用

```javascript
import { Unifiles } from 'unifiles'

const unifiles = new Unifiles()
// 开始使用
```

## 主要特性

* **统一接口** - 提供一致的 API 来操作不同类型的文件
* **多平台支持** - 支持本地文件系统、云存储等多种存储方案
* **类型安全** - 完整的 TypeScript 类型定义
* **高性能** - 优化的文件操作性能
