# Welcome to Unifiles

Unifiles is a unified file management system that helps you manage and organize files more efficiently.

## Quick Start

### Installation

```bash
# Install dependencies
npm install unifiles
```

### Basic Usage

```javascript
import { Unifiles } from 'unifiles'

const unifiles = new Unifiles()
// Start using
```

## Key Features

* **Unified Interface** - Provides a consistent API for different file types
* **Multi-platform Support** - Supports local file systems, cloud storage, and more
* **Type Safe** - Complete TypeScript type definitions
* **High Performance** - Optimized file operation performance
