# Copyright and contribution provenance

The current public rights contact is `meidici911@gmail.com`. An email address is
a contact identity, not a legal entity and not a copyright assignment. The legal
owner for any commercial transfer must be documented separately.

The project uses Apache-2.0 for the published work. Contributors keep rights to
their original contributions unless a separate written assignment applies.
Before accepting third-party code, maintainers record its source, license, and
permission to redistribute it.

For a future acquisition or transfer, the maintainers should provide a private
provenance package containing contributor agreements, employee IP assignments,
third-party notices, dependency license reports, and release records. Do not
commit those private documents to this repository.
