## 项目概述

Unifiles 是一个专为企业级应用设计的、支持高并发的智能文件处理服务。它提供从文件存储、内容提取、到知识库索引的全链路功能。

### 核心特性

- **三层API设计**: 清晰的文件、处理、知识库分层。
- **Markdown核心**: 所有文档被处理为标准的Markdown，实现内容与表现分离。
- **异步处理流水线**: 高性能、可扩展的文档处理能力。
- **企业级存储**: 基于 MinIO 和 PostgreSQL (pgvector) 构建，稳定可靠。
