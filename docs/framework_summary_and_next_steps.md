# Unifiles 框架设计总结和下一步行动计划

## 设计方案总结

完整的企业级文档处理框架，采用PostgreSQL + MinIO作为底层存储，实现三层业务流水线架构。

### 核心架构特点



#### 2. 技术栈选择
- **Web框架**: FastAPI (异步支持，高性能)
- **数据库**: PostgreSQL 16 + pgvector (向量存储)
- **对象存储**: MinIO (S3兼容，本地部署)
- **任务队列**: Dramatiq
- **认证**: JWT + Bearer Token + RLS
- **监控**: Prometheus + Grafana

#### 3. 核心设计理念
- **以Markdown为核心**: 统一内容格式，一次提取多次使用
- **异步处理优先**: 接口秒返回，后台异步处理
- **分层解耦**: 每层职责明确，接口清晰
- **企业级安全**: 行级安全，权限控制，审计日志
