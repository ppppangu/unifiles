# Features

Unifiles 采用三层架构设计，为您提供完整的文档处理和知识库管理解决方案。

## 三层架构概览

```
┌─────────────────────────────────────────┐
│  第三层：知识库管理                        │
│  - 向量化与语义检索                        │
│  - 多知识库隔离                           │
│  - 智能分块策略                           │
└─────────────────────────────────────────┘
                  ↑
┌─────────────────────────────────────────┐
│  第二层：内容提取                          │
│  - OCR 文本提取                           │
│  - 格式转换                               │
│  - Markdown 标准化                        │
└─────────────────────────────────────────┘
                  ↑
┌─────────────────────────────────────────┐
│  第一层：文件管理                          │
│  - 文件上传下载                           │
│  - 对象存储                               │
│  - 元数据管理                             │
└─────────────────────────────────────────┘
```

## 第一层：文件管理

### 文件上传
- 支持多种文件格式（PDF, Word, PPT, Excel, 图片等）
- 大文件分块上传
- 断点续传
- 文件格式自动检测

### 存储管理
- MinIO 对象存储集成
- 自动备份
- 存储空间配额管理
- 文件生命周期管理

### 元数据管理
- 文件基本信息（名称、大小、类型、创建时间等）
- 文件处理状态跟踪
- 文件关系管理
- 自定义元数据标签

### 访问控制
- 基于 API Key 的认证
- 文件级别权限控制
- 多租户隔离
- 访问日志记录

## 第二层：内容提取

### OCR 文本提取
- 高精度 OCR 识别
- 多语言支持
- 表格识别
- 公式识别

### 格式转换
- 统一转换为 PDF
- 保留原始格式信息
- 图片嵌入处理
- 批量转换

### Markdown 标准化
- 以 Markdown 为单一真实来源（SSOT）
- 图片引用管理
- 内容结构化
- 一次提取，多次使用

### 处理流水线
- 可配置的处理阶段
- 异步任务队列
- 错误重试机制
- 处理状态实时反馈

## 第三层：知识库管理

### 知识库创建
- 多知识库支持
- 知识库隔离
- 自定义配置
- 批量导入文档

### 文档索引
- 引用已提取内容
- 避免重复存储
- 灵活的分块策略
- 自动向量化

### 分块策略
- 固定长度分块
- 语义分块
- 层次化分块
- 自定义分块规则

### 向量搜索
- pgvector 高性能检索
- 相似度搜索
- 混合检索（关键词 + 向量）
- 结果排序与过滤

## 可观测性

### 日志系统
- 统一日志格式
- 多级别日志
- 日志持久化
- 日志搜索与分析

### 监控告警
- OpenTelemetry 集成
- 分布式追踪
- 性能监控
- 自定义指标

### 错误处理
- 优雅的错误恢复
- 详细的错误信息
- 错误追踪
- 自动重试

## 性能特性

### 高性能
- 异步 I/O
- 连接池管理
- Redis 缓存
- 批量处理

### 高可用
- 无状态设计
- 水平扩展
- 负载均衡
- 故障转移

### 可扩展
- 插件化架构
- 自定义处理器
- 灵活的配置系统
- 模块化设计
